## train_ddpm.py

### UNet（base=64, ch_mult=(1,2,4)）

- **下采样路径**：3 个下采样块（64→128→256 通道），每块含 TimeEmbedding 注入的 ResidualBlock + Downsample。
- **瓶颈**：256 通道 + 注意力。
- **上采样路径**：3 个上采样块，U-Net 跳跃连接。
- **注意力**：在 8×8 和 16×16 特征图（base=64 时的最深层）使用 MultiHeadAttention。
- **时间嵌入**：正弦位置编码 → MLP，注入每个残差块。
- 参数：**11.85M**。

### DiffusionSchedule

| 属性 | 说明 |
|------|------|
| beta | 线性调度 1e-4 → 2e-2，T=1000 |
| alpha | 1 - beta |
| alpha_bar | cumprod(alpha) |
| alpha_bar_prev | cat([1.0, alpha_bar[:-1]])（**关键修复**） |
| posterior_mean_coef1/2 | 后验均值系数（正确公式） |
| posterior_variance | 后验方差 |

### 关键方法

| 方法 | 作用 |
|------|------|
| q_sample(x0, t) | 前向加噪：x_t = sqrt(ab_t)*x0 + sqrt(1-ab_t)*eps |
| p_mean_variance(model, x, t) | 逆向：预测 eps → x0_hat → 后验均值/方差 |
| sample(model, shape) | 完整采样：x_T ~ N(0,I)，逐步去噪，记录过程 |

### 训练目标

`L = MSE(model(x_t, t), noise)`，用 AdamW lr=2e-4。

### 命令行

~~~bash
python code/train_ddpm.py --mode test|train|sample
  --data-root data      数据根目录
  --out-dir output_diffusion
  --ckpt path           采样用 checkpoint
  --epochs 100
  --batch-size 128
  --lr 2e-4
  --T 1000              扩散步数
  --base 64             UNet 基础通道
  --ema                开启 EMA（decay 0.9999）
  --n-samples 64
~~~

## train_fid_classifier.py

加载 ImageNet 预训练 ResNet-18，替换 fc 为 10 类，在 CIFAR-10 上微调 30 epoch（CosineAnnealing），保存 `fid_clf.pt`。

## compute_fid.py

1. 加载 `fid_clf.pt`，挂 `avgpool` 前向 hook 提取 512 维特征。
2. 从 CIFAR-10 测试集提取真实特征（截取 n_real=10000）。
3. 从 `samples.png` 读回生成图（32×32 cell，pad=2），归一化到分类器输入分布。
4. 用 Fréchet 距离（对称矩阵平方根，eigh 数值稳定）计算 FID。

## plot_ddpm.py

- `training_loss.png`：loss vs epoch 曲线。
- `samples_preview.png`：将 `samples.png` 放大 4 倍（274×274 → 1096×1096）。
