# 操作步骤

按顺序执行以下命令（在仓库根目录）：

## 第 0 步：准备

~~~bash
pip install -r requirements.txt
python download_data.py
~~~

## 第 1 步：训练 DDPM

~~~bash
# 100 epoch，开启 EMA，每 10 epoch 存一次 checkpoint
python code/train_ddpm.py --mode train --epochs 100 --ema --save-every 10
~~~

输出：`output_diffusion/ddpm_last.pt`（每 10 epoch 更新）和 `train_history.json`（全部 epoch loss）。

**注意**：本实验因断电在 epoch 60 中断，`ddpm_last.pt` 为 epoch 60 权重。完整跑 100 epoch 约 2 小时。

## 第 2 步：采样

~~~bash
python code/train_ddpm.py --mode sample --ckpt output_diffusion/ddpm_last.pt --n-samples 64
~~~

输出：`output_diffusion/samples.png`（8×8 网格）和 `progression.png`（去噪过程）。

## 第 3 步：训练 FID 特征提取器

~~~bash
python code/train_fid_classifier.py
~~~

训练一个 ResNet-18（ImageNet 预训练 + CIFAR-10 微调）作为特征提取器，保存 `output_diffusion/fid_clf.pt`。

## 第 4 步：计算 FID

~~~bash
python code/compute_fid.py --data-root data --out-dir output_diffusion --device cuda
~~~

输出：`output_diffusion/fid_result.json`（含 FID 值）。

## 第 5 步：可视化

~~~bash
python code/plot_ddpm.py --out-dir output_diffusion
~~~

输出：`training_loss.png`（loss 曲线）和 `samples_preview.png`（4 倍放大采样图）。
