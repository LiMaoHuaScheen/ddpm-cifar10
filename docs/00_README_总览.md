## 一句话结论

从零手写 DDPM（不依赖 diffusers）在 CIFAR-10 上可行：60 epoch 后 loss 收敛到 0.0314，采样图清晰分辨 10 个类别。训练因断电在 60/100 中断，FID=587 反映训练不足而非架构问题。期间修复了一个**采样公式 bug**（后验均值系数误用 `sqrt(alpha_t)`），是本次实验最重要的技术收获。
