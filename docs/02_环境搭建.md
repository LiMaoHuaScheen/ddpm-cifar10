# 环境搭建

## 1. 硬件

| 项 | 值 |
|----|-----|
| GPU | NVIDIA GeForce RTX 5060 Laptop，8GB 显存 |
| 驱动 | 621.24 |
| CUDA | 12.8（torch 2.11.0+cu128） |

## 2. Python 与依赖

~~~bash
# 建议 Python 3.10+（本机用 3.12.14）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install numpy pillow matplotlib
~~~

或直接：

~~~bash
pip install -r requirements.txt
~~~

## 3. 验证 torch + CUDA

~~~bash
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.version.cuda)"
~~~

期望输出：`2.11.0+cu128 True 12.8`

## 4. 数据准备

~~~bash
python download_data.py
~~~

从镜像 `https://dataset.bj.bcebos.com/cifar/cifar-10-python.tar.gz` 下载并解压到 `data/cifar-10-batches-py/`。
