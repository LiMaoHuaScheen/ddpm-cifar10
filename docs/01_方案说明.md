# 方案说明：为什么做扩散模型

## 1. 在视觉线中的位置

视觉线三步走：**图像分类 → 目标检测 → 扩散模型**。

前两步是判别式任务（从图像学到类别/位置），第三步转向**生成式任务**（从噪声学到图像分布）。这展现了能力的完整跨度，是研究生申请中很有说服力的组合。

## 2. 为什么选扩散模型（DDPM）

1. **当下最热门的生成模型**：Stable Diffusion、DALL-E、Imagen 都建立在 DDPM 及其变体之上。掌握 DDPM 是理解现代生成式 AI 的门票。
2. **原理优雅**：前向加噪 + 逆向去噪，数学上等价于学习一个去噪网络。比 GAN 更稳定（无对抗训练、无模式坍缩）。
3. **可解释、可展示**：训练曲线、采样过程、FID 指标都是清晰可讲的实验产出。

## 3. 为什么从零实现（不用 diffusers）

1. **展示原理掌握**：`q_sample`（前向）、`p_mean_variance`（逆向）、噪声预测 `ε` 都自己写，面试时能讲清每个公式。
2. **避免网络问题**：本机下载 diffusers 及其依赖很慢，从零实现只用 torch + torchvision，依赖极简。
3. **参数可控**：UNet 结构、时间嵌入、注意力层都自己定义，便于调试与讲解。

## 4. DDPM 原理简述

### 前向加噪（q_sample）

给干净图像 x0 加噪，t 步后：

~~~
x_t = sqrt(alpha_bar_t) * x0 + sqrt(1 - alpha_bar_t) * eps,   eps ~ N(0, I)
~~~

其中 `alpha_t = 1 - beta_t`，`alpha_bar_t = prod(alpha_1..alpha_t)`，`beta_t` 为线性调度 1e-4→2e-2。

### 逆向去噪（p_mean_variance）

从 x_T ~ N(0,I) 出发，逐步去掉噪声。模型预测噪声 `eps = model(x_t, t)`，再还原 x0：

~~~
x0_hat = (x_t - sqrt(1 - alpha_bar_t) * eps) / sqrt(alpha_bar_t)
~~~

后验均值 `q(x_{t-1} | x_t, x0)` 的系数为：

~~~
coef1 = beta_t * sqrt(alpha_bar_{t-1}) / (1 - alpha_bar_t)
coef2 = sqrt(alpha_t) * (1 - alpha_bar_{t-1}) / (1 - alpha_bar_t)
mean  = coef1 * x0_hat + coef2 * x_t
~~~

### 训练目标

最小化模型预测噪声与真实噪声的 MSE：

~~~
L = || model(x_t, t) - eps ||^2
~~~

## 5. 为什么选 CIFAR-10

1. **与第一步同数据集**：延续性，能对比生成与判别两种视角。
2. **32×32 小图**：DDPM 在 8GB 显存上可训练，~70s/epoch，100 epoch 约 2 小时。
3. **10 类清晰**：采样结果一眼可辨，适合展示。

## 6. 关键指标

| 指标 | 说明 |
|------|------|
| MSE loss | 噪声预测误差，越低越好 |
| FID | Fréchet Inception Distance，越低越好（完整收敛约 3~10） |
| 采样图 | 直观质量 |

## 7. 局限性

1. 60 epoch 训练不足（因断电中断），FID 偏高，属诚实结果。
2. 未用 EMA 采样（`--ema` 未开启），可进一步降低 FID。
3. 未做 512/1024 步完整收敛对比。
